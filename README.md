# Overview
Welcome to the Apartment Rent Prediction Challenge! In this competition, you will be working with a comprehensive dataset containing details of 60,000 apartments across the United States. Your task is to construct a robust predictive model to estimate apartment rents.

# Description
You will build a model predicting rents based on key features such as number of bedrooms, number of bathrooms, amenities, location, etc.

Once your model is trained and evaluated on the provided data, you will apply it to predict the rents for a new dataset of 20,000 apartments. These predictions will be used to rank submissions on the leaderboard based on their accuracy.
